## 遇到的问题

- Electron 安装问题：ELECTRON_RUN_AS_NODE=1 环境变量导致 Electron 以纯 Node.js 模式运行，require('electron') 返回路径字符串而非 API 对象。通过在 main.js 中添加 `delete process.env.ELECTRON_RUN_AS_NODE` 解决。
- npm 缓存权限问题：部分缓存文件属于 root 用户，使用本地缓存目录 .npm-cache 绕过。
- electron-auto-launch 版本号错误：1.0.0 不存在，修正为 5.0.7。
