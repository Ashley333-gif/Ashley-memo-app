# AshleyMemo 分步执行计划

## 阶段 1：项目初始化
**目标**：Electron 项目跑起来，菜单栏显示图标

1. 初始化 npm 项目，安装依赖
2. 创建 main.js — 基础 Electron 应用 + 菜单栏托盘
3. 创建 preload.js — IPC 通信桥梁
4. 空白窗口从托盘图标点击弹出/收起
5. 准备应用图标和托盘图标（18×18 / 36×36 模板图）
6. 验证：点击图标弹出窗口，点击外部收起

## 阶段 2：数据库 + 剪贴板监听
**目标**：自动记录复制的文字和图片

1. 创建 database.js — SQLite 初始化、建表、CRUD 操作
2. 创建 clipboard.js — 500ms 轮询剪贴板变化
3. 文字内容写入 history 表
4. 图片内容保存到 images/ 并写入 history 表
5. 实现过期清理逻辑
6. 验证：复制内容后在数据库可见

## 阶段 3：主界面 — 卡片列表
**目标**：弹出窗口展示剪贴板历史

1. 创建 index.html 整体布局
2. 创建 style.css 粉色主题样式
3. 创建 app.js 前端渲染逻辑
4. 卡片渲染（文字 + 图片缩略图）
5. 时间降序排列，置顶分隔
6. 验证：卡片列表正确显示

## 阶段 4：交互功能
**目标**：置顶、删除、搜索、点击复制

1. 置顶/取消置顶切换
2. 删除记录（含图片文件清理）
3. 搜索框实时过滤
4. 点击文字卡片复制到剪贴板
5. 图片缩略图点击大图预览
6. 验证：所有交互功能正常

## 阶段 5：设置功能
**目标**：保留时长 + 开机自启

1. 底部设置栏（1天/3天/5天切换）
2. 设置持久化读写
3. 集成 electron-auto-launch
4. 验证：设置生效，重启后自动运行

## 阶段 6：打磨与打包
**目标**：细节优化 + 生成 .dmg

1. UI 细节打磨（动画、滚动条、间距）
2. 空状态页面
3. 应用图标设计
4. electron-builder 配置
5. 生成 .dmg 安装包
6. 完整流程测试
