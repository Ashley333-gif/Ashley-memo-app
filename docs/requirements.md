# AshleyMemo 用户需求文档

## 项目名称
AshleyMemo — Mac 剪贴板历史管理器

## 核心需求

### 1. 剪贴板自动记录
- 自动监听 Mac 系统剪贴板变化
- 记录所有复制的内容，包括文字和图片
- 不需要用户手动操作，后台静默运行

### 2. 内容保留时长
- 用户可设置保留时长：1天 / 3天 / 5天
- 超过保留期的记录自动清除（包括关联的图片文件）
- 置顶内容不受过期影响

### 3. 历史浏览
- 所有记录以时间降序排列（最新在最上）
- 每条记录显示为一张独立卡片
- 文字卡片：显示文字内容预览（最多2行）
- 图片卡片：显示缩略图

### 4. 交互功能
- 置顶：重要内容可固定在列表顶部，不受时间排序影响
- 删除：单条记录可删除（含图片文件）
- 搜索：输入关键词实时过滤卡片列表
- 点击文字卡片：将该内容重新复制到剪贴板
- 点击图片缩略图：弹出大图预览

### 5. 打开方式
- Mac 菜单栏常驻小图标
- 点击图标弹出历史面板
- 点击面板外区域自动收起

### 6. 开机自启
- 电脑开机后自动在后台运行
- 用户可在设置中开关此功能

### 7. UI 设计要求
- 简洁风格，避免复杂操作
- 主题色：粉色（主色 #FF85A2）
- 窗口尺寸：360×520 像素
- 圆角卡片，轻微阴影
- 系统默认中文字体

## 非功能性需求
- 仅支持 macOS 平台
- 不排除任何应用的复制内容（全部记录）
- 软件运行轻量，不占用过多系统资源
